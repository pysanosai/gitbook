# Création d’un compte vendeur

### **Créer un compte**

<figure><img src="../../.gitbook/assets/image (5) (1).png" alt="" width="292"><figcaption></figcaption></figure>

1. Va sur la page d’inscription eCamson.
2. Entre ton **adresse e-mail**.
3. Sélectionne **« Je suis un vendeur »** (illustré page 8-9).
4. Clique sur **S’inscrire**&#x20;





### Compléter les informations vendeur

<figure><img src="../../.gitbook/assets/image (6) (1).png" alt="" width="255"><figcaption></figcaption></figure>

remplis le formulaire vendeur :

* Prénom
* Nom de famille
* Nom de la boutique
* URL du magasin
* Numéro de téléphone
* Adresse professionnelle



### **E-mail de bienvenue eCamson – Votre compte a bien été créé !**

<figure><img src="../../.gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure>

Un message de confirmation affichant l’activation du compte, les liens pour définir le mot de passe et vérifier l’adresse e-mail, ainsi que l’accès à l’espace membre.





<figure><img src="../../.gitbook/assets/https___files.gitbook.com_v0_b_gitbook-x-prod.appspot.com_o_spaces_2Fel3vQ4kdSgriCm83f7Fw_2Fuploads_2FzDbqtNUBIhvSGFIaTkAS_2Fimage.avif" alt=""><figcaption></figcaption></figure>

Votre compte a été créé avec succès.



**Prochaine étape : Validation du compte**

Après avoir rempli votre profil et envoyé les documents demandés (identité, adresse, RIB…), votre dossier sera examiné par l’équipe eCamson.\
La validation peut prendre entre 24 et 72 heures.\
Vous recevrez un e-mail dès que votre boutique sera **approuvée** ou qu’une correction sera nécessaire.\
