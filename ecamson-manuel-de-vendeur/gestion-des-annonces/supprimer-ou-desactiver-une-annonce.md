# Supprimer ou désactiver une annonce

## S**upprimer ou Désactiver une Annonce (Produit)**

La marketplace eCamson offre deux méthodes pour retirer un produit de votre boutique :\
&#x20;**le supprimer définitivement**,\
ou\
&#x20;**le désactiver temporairement** (le cacher).

Les deux options ont des effets différents. Voici comment les utiliser efficacement.

## **Supprimer définitivement un produit**

Cette action efface totalement le produit de votre boutique.

#### 🔧 Comment faire ?

1. Aller dans **Produits**.
2. Trouver le produit à supprimer.
3. Cliquer sur **Supprimer définitivement** (texte rouge), sous le nom du produit.\
   &#xNAN;_(voir première image)_

#### ⚠️ Attention

* L’action est **irréversible**.
* Le produit disparaît complètement de votre catalogue et de votre tableau de bord.
* Vous ne pourrez plus le restaurer.

## **Désactiver / Cacher un produit (recommandé si temporaire)**

Si vous ne souhaitez pas supprimer un produit, mais seulement le rendre invisible pour les clients, utilisez l’option **Visibilité**.

#### 🔧 Comment faire ?

1. Aller dans **Produits → Modifier**.
2. Descendre jusqu’à la section **Autres options**.
3. Dans le champ **Visibilité**, choisir l’un des modes suivants :
   * **Visible** : affiché partout (boutique + résultats de recherche)
   * **Catalogue** : visible dans la boutique, mais pas dans la recherche
   * **Recherche** : visible uniquement dans la recherche
   * **Caché** : complètement invisible pour les clients

Sélectionnez **Caché** pour désactiver l’annonce sans la supprimer.\
&#xNAN;_(voir deuxième image)_

#### ✔ Avantage

* Le produit reste dans votre catalogue interne.
* Vous pouvez le réactiver quand vous voulez, en remettant la visibilité sur "Visible".
