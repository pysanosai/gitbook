# Modifier une annonce

La page **Modifier le produit** permet au vendeur d’actualiser les informations de ses fiches produits : titre, prix, description, stock, images, attributs, options de retour, etc. Cette section du tableau de bord est essentielle pour maintenir un catalogue à jour, corriger des erreurs ou optimiser les fiches produits pour augmenter les ventes.

## **Accéder à la modification d’un produit**

Depuis le tableau de bord :

1. Aller dans **Produits**
2. Choisir un produit dans la liste
3. Cliquer sur **Modifier**

L’interface complète de modification s’ouvre alors.

### Les éléments essentiels à mettre à jour

#### **• Titre du produit**

Corriger ou préciser le nom du produit si nécessaire.

#### **• Catégorie**

S’assurer que le produit est placé dans la bonne catégorie.

#### **• Prix / Prix promotionnel**

Modifier le prix principal ou activer une promotion temporaire.

#### **• Images**

Mettre à jour l’image principale ou ajouter/enlever des images de la galerie.

#### **• Courte description**

Réajuster les points forts affichés sous le prix.

#### **• Description complète**

Corriger ou enrichir le texte principal (caractéristiques, détails techniques).

#### **• Inventaire (stock)**

Modifier :

* statut du stock (en stock / rupture)
* quantité disponible
* SKU si nécessaire

#### **• Expédition**

Corriger le poids, dimensions ou classe d’expédition si le produit change de format.

#### **• Options RMA / Politique de retour**

Mettre à jour la garantie ou les conditions de retour si elles changent.

#### **• Visibilité et statut du produit**

* **Publié** → Visible sur la boutique
* **Brouillon** → Non visible
* **Privé** → Visible seulement par le vendeur



### Enregistrer les modifications

Lorsque les changements sont faits, cliquer sur :\
&#x20; **Enregistrer le produit**

Les modifications sont appliquées immédiatement sur la boutique.
